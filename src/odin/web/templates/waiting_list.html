How approval works

Approve replaces production's row(s) for that key with the held rows (restated = true); the prior values stay visible in provenance. Merge keeps both — inserts the held rows alongside the existing ones (restated = false), for a collision that is a genuine additional record. Reject drops the held rows untouched. Reject all clears every batch matching the current filter.
