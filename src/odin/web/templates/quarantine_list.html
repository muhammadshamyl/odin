Why quarantine

The 256-char cap is not cosmetic: one long, incompressible string in an indexed production column exceeds Postgres's btree entry limit and jams the bulk insert for the whole batch. Re-inject copies rows back to staging under a fresh batch_id; run the transform to re-process. Still-bad rows re-quarantine. There is no patch-in-place.
